# Simuladores de Examen

Banco de simuladores de examen para autoevaluación. Cada simulador es una página HTML autónoma con preguntas de práctica tipo examen, pensada para repasar antes de una evaluación real.

Este repositorio incluye una página principal (`index.html`) que enlaza a los tres simuladores disponibles.

## Materias disponibles

### 🔧 Sistemas Digitales
- **Archivo:** [`simulacro_sistemas_digitales.html`](./simulacro_sistemas_digitales.html)
- **Contenido:** Circuitos lógicos, álgebra booleana, compuertas, y diseño digital combinacional y secuencial.
- **Uso:** Abre el archivo directamente en el navegador, o accede desde el enlace correspondiente en `index.html`.

### 🗄️ Administración de Bases de Datos
- **Archivo:** [`Simulador_ABD.html`](./Simulador_ABD.html)
- **Contenido:** Modelado de datos, diseño relacional, SQL y administración de bases de datos.
- **Uso:** Abre el archivo directamente en el navegador, o accede desde el enlace correspondiente en `index.html`.

### 🖱️ Interacción Humano-Computador
- **Archivo:** [`simulador_ihc.html`](./simulador_ihc.html)
- **Contenido:** Principios de usabilidad, diseño de interfaces y experiencia de usuario (UX/UI).
- **Uso:** Abre el archivo directamente en el navegador, o accede desde el enlace correspondiente en `index.html`.

## Cómo usarlo

1. Abre `index.html` para ver el menú principal con las tres materias.
2. Haz clic en el simulador que quieras practicar; se abrirá en la misma pestaña.
3. Responde las preguntas y revisa tu resultado al finalizar cada simulacro.

## Despliegue

Este proyecto está pensado para desplegarse en [Vercel](https://vercel.com) como sitio estático y usarse cómodamente desde el celular. Al desplegarlo, `index.html` funcionará como página de inicio y dará acceso directo a los tres simuladores.
